## Lessons Learned
- Cache hit rate 93.6% menunjukkan Hermes prompt caching sangat efektif — tidak perlu optimasi tambahan
- glm-5.2 lebih konsisten latency-nya (max 60s vs 453s) — cocok untuk latency-sensitive paths
- Rate limit hanya terjadi saat concurrent request overlap — scheduling cron jobs lebih spread out bisa help
- Session compression di 182K tokens menunjukkan long-running WhatsApp agent mendekati limit — perlu proactive rotation
