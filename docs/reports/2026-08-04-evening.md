# Daily Report 2026-08-04 — Evening: Website Data Accuracy Audit

## Engineering Question
"Apakah data yang ditampilkan homepage dan sitemap tabaco.id masih akurat setelah 3 hari engineering work berturut-turut?"

## Method
Cross-check homepage stats (`src/data/site.ts`) dan sitemap (`public/sitemap.xml`) terhadap kondisi aktual: jumlah reports di `docs/reports/`, phase terkini dari CHANGELOG, routes aktif di `App.tsx`, dan nav items di `site.ts`.

## Findings

### 1. Homepage Stats (stale)

| Field | Sebelum (di site.ts) | Aktual |
|---|---|---|
| Days running | "Day 1" | Day 3 (2026-08-04) |
| Phase | "Phase 0 — Foundation" | Phase 1 — Lab Infrastructure (reports feed, SEO basics done) |
| Detail | "Phase 0: foundation reframe" | 10 reports, multiple benchmarks |

Homepage menampilkan data yang 2 hari stale. Ini menurunkan credibility — website klaim "living engineering lab" tapi data-nya frozen.

### 3. Webreader container health
- `webreader-nginx` dan `webreader-api` keduanya up 43 hours. Healthy.

### 4. Afternoon cron failure
- `Afternoon Engineering — Core & Experiments` cron gagal karena HTTP 429 rate limit (z.ai) pada 12:00 WIB, lalu idle timeout 603s.
- Root cause: concurrent requests (cron + gateway) hit rate limit, retry gagal karena limit masih active.
- Consistent dengan temuan token audit: rate limit terjadi pada overlap jam 19:00-21:00 WIB (tapi ini 12:00 — outlier karena pagi juga ada morning run).

## Decision
**Adopt** — fix homepage stats + tambah `/reports` ke sitemap. Dua diff kecil, data akurat, build pass.

## Risk
Sangat rendah. String statis di `site.ts` dan entry XML di sitemap. Rollback = revert 2 file.

## Lessons Learned
- Homepage stats harus diupdate setiap kali ada milestone. Tapi manual update = stale risk. Solusi jangka panjang: pull data dari CHANGELOG atau reports directory secara dinamis.
- Sitemap harus selalu sync dengan App.tsx routes. `/reports` ditambahkan ke router tapi lupa update sitemap — celah kecil tapi impact-nya crawler tidak menemukan halaman.

## Next Priority
- Automated sitemap generation (baca routes dari App.tsx / nav items, bukan manual)
- Homepage stats dari data dinamis (bukan hardcoded strings)
