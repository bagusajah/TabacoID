## Objective
Menutup item terakhir Phase 0.4 (SEO basics) dengan menambahkan JSON-LD Organization structured data ke `index.html`.

## Context
Phase 0 audit mencatat 4 item: reframe hero, strip agency copy, hapus dead deps, SEO basics. Tiga yang pertama sudah diselesaikan di Cycle 1–3 (commit `25ea811`, `4771875`, `9a5de3d`). ## What Changed (files + reason)
- **`index.html`** — tambah satu `<script type="application/ld+json">` block dengan schema `Organization` (name, url, description, email).
- **Alasan:** Mesin pencari menggunakan JSON-LD untuk rich results dan entity recognition. Tanpa structured data, Google cuma melihat meta description sebagai teks biasa — gak ada signal kuat bahwa TabacoID adalah entitas terdefinisi (sebuah laboratory), bukan sekadar halaman web. Ini baseline SEO, bukan optimisasi prematur.
- **Field dipilih dengan akurat:**
  - `name`: dari `brandName` di `src/data/site.ts` = "TabacoID"
  - `email`: dari `contactEmail` = "bagusmukmin@tabaco.id"
  - `description`: selaras dengan meta description + hero copy yang ada
  - `url`: canonical domain

## Risk
**Sangat rendah.**
- JSON-LD adalah data statis di `<head>` — gak ada runtime cost, gak hook ke React lifecycle, gak nambah JS bundle.
- Rollback = hapus satu `<script>` block (8 baris).
- Gak ada dependency baru. Gak ada perubahan struktur aplikasi.

## Lessons Learned
- **Ponytail ladder rung 6: "Can it be one line?"** JSON-LD adalah satu block statis di HTML, bukan komponen React dinamis. Gak perlu helmet, gak perlu react-helmet-async, gak perlu data-driven schema generator. Static HTML di tempat yang sudah benar (`<head>`) adalah solusi paling lazy dan paling reliable untuk konten yang jarang berubah.
- **Audit dulu sebelum kerja.** Phase 0 backlog menyebut "SEO basics" sebagai satu item, tapi kenyataannya meta tags + OG sudah ada dari Phase 0 kickoff. Hanya JSON-LD yang belum. Tanpa verifikasi (`search_files` untuk `application/ld+json`), aku bisa saja menduplikasi kerja atau menambah meta tags yang sudah ada.
- **Phase 0 selesai.** Semua 4 item Phase 0 (reframe, strip, dead deps, SEO) sekarang lengkap. Next: Phase 1 (static gen, status page, daily report feed, robots.txt + sitemap.xml).
