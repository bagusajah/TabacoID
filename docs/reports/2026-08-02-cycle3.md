## Lessons Learned
1. **Dead dependency = pure cost.** Tiap lib di `package.json` adalah janji maintenance, upgrade, CVE patch, dan lockfile churn. Dead code gak ada return — hanya cost. Hapus duluan sebelum nambah yang baru.
2. **`npm install` output "removed N packages" itu metric terukur.** Bukan cuma angka — itu adalah transitive dependency surface yang berhasil di-eliminasi. Lebih sedikit package = lebih sedikit serangan CVE.
3. **Bundle hash gak berubah = bukan failure.** Build cache valid, tree-shaking Vite udah handle dead code dengan baik. Buat kasus dead-dep removal, metricnya bukan `dist/` size, tapi `node_modules/` size + `npm audit` surface.
4. **Hook definition tanpa caller adalah dead code paling sering ke-skip.** Karena gak trigger lint error, gak trigger build error. Audit "defined tapi gak dipanggil" harus explicit — grep nama export di seluruh codebase.
