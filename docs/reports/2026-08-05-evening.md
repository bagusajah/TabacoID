# Daily Report 2026-08-05 — Evening: Vercel SPA Routing Fix

## Pertanyaan Engineering
Kenya live site tabaco.id return 404 di semua route kecuali `/` padahal build passing dan client-side route ada?

## Metode
1. `curl -s https://www.tabaco.id/reports` — konfirmasi 404
2. Cek keberadaan `vercel.json` dan `public/_redirects` — keduanya tidak ada
3. Verifikasi homepage masih jalan (`curl https://www.tabaco.id/` → 200, HTML OK)
4. Root cause: Vercel default hanya serves static files dari `dist/`. SPA client-side routing (`/reports`, `/about`, dll) membutuhkan server-side rewrite semua route → `index.html`
5. Fix: buat `vercel.json` dengan rewrite rule
6. Bonus: update homepage stale stats (Day 3→4, 10→13 reports) dan sitemap lastmod

## Temuan (dengan pengukuran)

### Root Cause
| Fakta | Nilai |
|-------|-------|
| `vercel.json` exists | ❌ Tidak ada |
| `public/_redirects` exists | ❌ Tidak ada |
| Route `/` (homepage) | 200 OK ✅ |
| Route `/reports` | **404** ❌ |
| Route `/about` | **404** ❌ (diasumsikan, pattern sama) |
| Total broken routes | 4 dari 5 (semua kecuali `/`) |

**Impact:** Seluruh website — reports page, about, contact, experiments — tidak accessible di production sejak project dimulai (2026-08-02). Hanya homepage yang jalan. Ini production bug tertutup karena belum ada yang navigate langsung ke URL non-root.

### Lainnya Ditemukan
- Report parser (`Reports.tsx`) tidak mengenali format report saat ini (`## Decision`) — hanya mencari `**Decision:**` yang tidak ada di report manapun. Semua reports ditampilkan tanpa category dan decision badge.
- Homepage stats stale: "Day 3", "10 reports" — seharusnya "Day 4", "13 reports"

## Perbaikan
| File | Perubahan |
|------|-----------|
| `vercel.json` (baru) | SPA rewrite: semua route → `/index.html` |
| `src/data/site.ts` | Day 3→4, 10→13 reports |
| `public/sitemap.xml` | lastmod 2026-08-04 → 2026-08-05 |

## Keputusan
**Adopt** — production routing bug fix. 3 file, semua reversible. `vercel.json` adalah config file, bukan code — risiko minimal.

## Risiko
- Rewrite rule catch-all — jika nanti ada API route atau static file yang seharusnya 404, akan serve `index.html` instead. Acceptable: project ini 100% SPA, tidak ada API routes di Vercel.
- Report parser masih broken (category/decision kosong) — deferred ke cycle berikutnya, bukan blocking untuk routing fix.

## Lessons Learned
1. **Vite CSR SPA + Vercel = wajib `vercel.json` rewrite.** Tanpa ini, hanya `/` yang jalan. Ini basic integration yang terlewat sejak day 1.
2. **404 di production tidak terdeteksi oleh build.** `npm run build` pass tapi production broken — CI hanya cek build, tidak cek routing.
3. **Stale data akumulasi cepat** — homepage stats harus part of data layer yang bisa diupdate per cycle, bukan hardcode di `site.ts`. Tapi saat ini hardcode acceptable, cuma perlu di-update rutin.

## Prioritas Berikutnya
- Fix report parser — `Reports.tsx` perlu parse `## Decision`, `## Method`, `## Engineering Question` (bukan `**Decision:**`)
- Verifikasi deploy ke production dan test `/reports` setelah `vercel.json` terdeploy
- Report page category/decision extraction — reports sekarang muncul tanpa metadata
