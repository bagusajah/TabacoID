## Method
1. ROADMAP.md TD-16 + `npm audit` baseline → 6 findings (aws-sdk + uuid chain, braces chain, sequelize-uuid).
2. Scan pemakai: `aws-sdk` hanya di `plugins/country-storage/index.js` — satu `_s3()` factory, tiga call site (`headObject().promise()`, `getSignedUrl('getObject'|'putObject', …)` — keduanya sudah `await`).

4. Plugin: `_s3()` sekarang `new S3()` (v3, default chain credential tetap) dibungkus facade `_s3v2Shape` — call site & seam `pluginConfig.s3` bentuk v2 tak tersentuh; error v3 diberi aksen v2 (`code` dari `name`, `statusCode` dari `$metadata.httpStatusCode`) supaya deteksi NotFound route byte-untouched.

6. Test: 1 unit baru (regression guard pemetaan error `_s3v2Shape`) → file 15/15; suite penuh `npm test` → **407/407**, exit clean.

## Findings
- `npm audit`: 6 → **5 findings** (0 critical, 3 high, 2 moderate). `aws-sdk` hilang dari tree; sisa temuan `uuid` kini murni nested uuid sequelize (`uuid@11` fix-nya; sequelize 6 pin `^8` → ikut bump sequelize 7).

- Lint: repo tidak punya config eslint (pre-existing, `npm run lint` memang kosong konfig) — tidak diutak-atik di inkremen deps.
