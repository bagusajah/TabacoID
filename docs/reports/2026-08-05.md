## Decision
**Adopt** — Full stack inventory terdokumentasi. Beberapa finding butuh tindak lanjut.

## Risk
1. **VPS unreachable** — host.tabaco.id SSH connection refused. Reverse proxy untuk hermes.tabaco.id mungkin down. Perlu investigasi.
2. **Load rata-rata 5.2 pada 4-core** — sustained high load. Hermes dashboard pakai 650 MB RSS (8.1% RAM). Perlu profiling.
3. **7 GB unused Docker images** — supabase stack dan n8n tidak berjalan tapi imagenya masih ada. Potensi cleanup 7 GB.
4. **rpcbind (port 111) exposed on 0.0.0.0** — tidak perlu untuk penggunaan saat ini. Security risk minor.
5. **ADB over TCP (port 5555) exposed on 0.0.0.0** — security risk jika tidak digunakan.
6. **Jellyfin exposed on 0.0.0.0:8096** — hanya perlu di LAN, tidak perlu globally accessible.

## Lessons Learned
- Inventory ini seharusnya sudah ada dari awal. Stack sudah cukup kompleks (54 services, 15 ports, 5 Tailscale nodes) untuk tidak punya map.
- VPS SSH down terdeteksi selama inventory — hal yang tidak akan ketahuan tanpa active scanning.
- DNS BIND listening di 7 interface berbeda (localhost, LAN, Tailscale, Docker bridges) — overkill untuk local resolver.

## Next Priority
1. Investigasi VPS reachability — apakah nginx reverse proxy masih serve hermes.tabaco.id?
2. Docker image cleanup — hapus unused supabase/n8n images (~7 GB)
3. Profiling load tinggi — apa yang menyebabkan sustained load 5+ pada 4-core?
