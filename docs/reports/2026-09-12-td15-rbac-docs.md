# TD-15 closed — RBAC permissions reference (docs/RBAC.md)

## Engineering Question

ROADMAP's "Next up" list is exhausted (items 1–13 all ✅). The last open,
autonomously-actionable item in Known issues was TD-15: *document that the
`calendar:force` permission must be granted narrowly (CAB/release-managers),
not bundled into broad roles.*

## Method

1. Read ROADMAP.md item: TD-15 (Low severity, Phase 2 calendar, ADR-0007).
2. Implemented (docs-only, no code):
   - `docs/RBAC.md` (new) — full permissions reference: matching semantics
     (logical name or `/api/x/*` path pattern, `*` wildcards, envScope),
     core permission table (apps/releases/secrets/calendar/impact/tracking/
     users/admin), plugin permission table (vault-replicator / release-train /
     batch-release / country-storage; jenkins-webhook's token auth noted), and
     a "grant narrowly" section: `calendar:force`, `admin:*`, `* / * / *`
     wildcard rows, `users:update`, `secrets:write` — each with why and who
     should hold it.
   - `README.md` — "What does NOT work yet" listed five completed items
     (booking-sync, TD-10, TD-11, OpenShift driver, all Phase 3 plugins);
     replaced with the two true gaps (TD-2 OIDC e2e, admin UI API-only).
     Linked RBAC.md.
   - `docs/decisions/README.md` — ADR index was missing 0010 and 0011
     (both files exist and are referenced by ROADMAP); added both rows.
   - `docs/ROADMAP.md` — TD-15 marked ✅ Closed, header updated.
3. Tested: `npm test` → 33 suites / 372 tests passed, exit 0, no flags
   (docs-only change; suite run is the green-baseline gate).

## Findings

  linked place rather than buried in an ADR consequence note.

  "not working yet" section was 5-for-5 stale, and the ADR index was 2 ADRs
  behind. Both repaired in the same commit.
- Verification details: permission inventory was taken from actual route
  files (every `requirePermission` call in `src/routes/` + `_reference.js` +
  `admin.routes.js`), not from memory; the middleware's dual logical-name /
  path-pattern matching in `src/middleware/auth.js` is documented as
  implemented.
- Remaining open items after this run: TD-2 (OIDC e2e — needs a real IdP,
  not autonomously actionable) and TD-4 (k8s-client ESM migration — future).
  **ROADMAP "Next up" is fully exhausted.** Future runs need either new
