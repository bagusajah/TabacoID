## 3️⃣ Insight Pola Minggu Ini

- **"Agent harness" adalah tema dominan**: 3 dari 8 repo (paperclip, openrig, univer) semuanya berposisi sebagai *harness/runtime* untuk mengelola atau menjalankan AI agents — pasar sedang melapuh pada lapisan orkestrasi di atas model, bukan pada model itu sendiri.
- **Lokal & privasi menang**: VoiceStudio (alternatif ElevenLabs fully-local) dan hindsight (memori agent lokal) menunjukkan permintaan kuat untuk tool yang tidak mengirim data ke cloud — lonjakan ribuan bintang/hari dicapai tanpa viral keras di HN, artinya pertumbuhan datang dari ekosistem GitHub/word-of-mouth sendiri.
- **Kecepatan rilis = kecepatan bintang**: hindsight, VoiceStudio, dan paperclip semuanya merilis versi baru atau merge PR besar dalam seminggu terakhir (21–29 Sep). Proyek yang trending hampir selalu yang punya aktivitas commit harian, bukan yang sekadar punya README bagus.
