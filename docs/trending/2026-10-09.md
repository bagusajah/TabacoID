## Riset 3 Repo Teratas

### 1. [boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5)
Proyek bintang hari ini (+4.669) ini adalah tool yang mem-port executable PS5 agar jalan native di Linux dan Windows tanpa emulasi, dan sekarang sudah punya dua release stabil: [v0.1.1](https://github.com/boykopovar/AnyPS5/releases/tag/v0.1.1) (28 September 2026) dan [v0.1.0](https://github.com/boykopovar/AnyPS5/releases/tag/v0.1.0) pada hari yang sama. Commit terakhirnya adalah [f145139](https://github.com/boykopovar/AnyPS5/commit/f145139676a48306681d3a4d5fabf83938759daf) (8 Oktober 2026), sebuah fix shader yang menerjemahkan `v_fma_mix_f32` sebagai fused multiply-add — menandakan penerjemahan shader masih terus ditingkatkan. Proyek ini juga sedang ramai dibahas di Hacker News: [AnyPS5: Port PS5 binaries to PC without emulation](https://news.ycombinator.com/item?id=49985664) dengan 365 poin dan 312 komentar.

### 2. [morluto/rea](https://github.com/morluto/rea)
Rea adalah tool reverse engineering berbasis agents — dari perilaku aplikasi hingga biner native — dan penambahan +7.738 bintang hari ini menjadikannya penambang bintang tercepat di daftar. Ritme rilisnya luar biasa rapat: [rea-agents v6.1.0](https://github.com/morluto/rea/releases/tag/rea-agents-6.1.0) dirilis hari ini (9 Oktober 2026), menyusul [v6.0.0](https://github.com/morluto/rea/releases/tag/rea-agents-6.0.0) dan [v5.0.0](https://github.com/morluto/rea/releases/tag/rea-agents-5.0.0) pada 8 dan 7 Oktober — total 32 rilis sejak Juli. Commit terbarunya, [089bbf5](https://github.com/morluto/rea/commit/089bbf58f3561e3f465c544bbcf8c307287b1256) (9 Oktober 2026), memperbaiki penanganan cancel (SIGINT) pada `rea analyze` untuk target JavaScript/ASAR, dengan co-author Claude Opus 5.5 — bukti nyata pengembangan berbantu AI. Diskusi kecil juga muncul di HN lewat [Reverse Engineer Anything](https://news.ycombinator.com/item?id=50012930).

### 3. [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)
Proyek ini menyediakan desain diagram bergaya editorial untuk AI coding agent seperti Claude Code, Codex, GitHub Copilot, Factory Droid, dan Pi — 42 tipe diagram dalam HTML + SVG mandiri, tanpa Mermaid. Repo ini tidak menerbitkan GitHub release sama sekali (tanpa release); distribusinya tampaknya lewat manifest plugin yang terus di-bump. Commit terakhirnya, [f4547ee](https://github.com/cathrynlavery/diagram-design/commit/f4547ee95f88e5b28a52517feff6b6c11cc657f9) (8 Oktober 2026), menaikkan manifest plugin ke versi 2.6.68. Belum ada thread HN yang spesifik membahas repo ini — pencarian Algolia hanya menghasilkan diskusi diagram designer lama yang tidak relevan.

## Insight Minggu Ini
- **AI agents mendominasi**: 4 dari 9 repo di daftar ([morluto/rea](https://github.com/morluto/rea), [mattpocock/skills](https://github.com/mattpocock/skills), [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem), [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)) berhubungan langsung dengan ekosistem AI agent — mulai dari skills, memori persisten, hingga plugin knowledge worker.

- **Rilis cepat jadi norma proyek naik daun**: [morluto/rea](https://github.com/morluto/rea) menerbitkan tiga major/minor release dalam tiga hari berturut-turut, menunjukkan proyek yang sedang tumbuh memilih iterasi harian yang terlihat publik.
