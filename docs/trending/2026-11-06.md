## Riset 3 Repo Teratas

### 1. NVIDIA/auto-ontology

[NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) melompat ke puncak trending dengan +2.679 bintang dalam sehari, didorong gelombang HN lewat diskusi [Nvidia – open-source auto-ontology](https://news.ycombinator.com/item?id=50348962) (289 poin, 3 November). Repo ini masih sangat muda: [daftar release-nya kosong](https://github.com/NVIDIA/auto-ontology/releases), jadi semua penggunaan masih di jalur main langsung. Aktivitasnya ramai — commit terakhir [c449567](https://github.com/NVIDIA/auto-ontology/commit/c4495670947eb7b4616f0dd9900e5ced2a48ca1e) "Bump version to 1.2.0" masuk 5 November 2026. Minatnya besar sampai memunculkan repo turunan dan alternatif di HN hanya dalam dua hari.

### 2. vercel-labs/agent-desktop

[vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop), CLI computer-use untuk agen AI, baru saja merilis versi stabil [v1.2.0](https://github.com/vercel-labs/agent-desktop/releases/tag/v1.2.0) pada 5 November 2026 — rilis kelimanya sejak v1.0.0 akhir Oktober, tanda ritme pengembangan yang sangat cepat. Commit terakhir [b43ac4f](https://github.com/vercel-labs/agent-desktop/commit/b43ac4f6e892ef608f8851428613c4009f0e84c7) (5 November) mengoptimalkan inventaris proses macOS dengan libproc, memangkas waktu capture dari ~80 ms ke ~7 ms. Proyek ini dulunya diperkenalkan lewat [Show HN: Agent-desktop](https://news.ycombinator.com/item?id=47982708) (99 poin) dan kini bertumbuh organik bersama [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) di ekosistem Rust.

### 3. mattpocock/skills

[mattpocock/skills](https://github.com/mattpocock/skills) kini menembus ★ 315.312 total, menjadikannya repo dengan basis bintang terbesar di daftar hari ini. Rilis terakhirnya adalah versi stabil [v1.3.2](https://github.com/mattpocock/skills/releases/tag/v1.3.2) pada 29 Oktober 2026, sedangkan commit terakhir [4ae2317](https://github.com/mattpocock/skills/commit/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d) (31 Oktober) menambahkan skill "glossary" untuk merancang software factory — ditulis bersama Claude Opus 5.5. Diskusi HN tentang framework ini masih terbatas, seperti [An honest review of Matt Pocock's Skills framework](https://news.ycombinator.com/item?id=50165607), namun adopsi komunitasnya jelas lewat angka bintang harian +2.071.

## Insight Minggu Ini

- Demam "skills" untuk agen AI makin panas: [mattpocock/skills](https://github.com/mattpocock/skills), [google/skills](https://github.com/google/skills), [scenario-labs/skills](https://github.com/scenario-labs/skills), [ConardLi/garden-skills](https://github.com/ConardLi/garden-skills), dan [garrytan/gstack](https://github.com/garrytan/gstack) naik bersamaan — kumpulan prompt/prosedur kini diperlakukan seperti paket perangkat lunak.
- Ekosistem Rust jadi tulang punggung tooling agen: [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) (+2.173), [max-sixty/worktrunk](https://github.com/max-sixty/worktrunk) (+546), dan [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) (+150) semua berbasis Rust dan fokus mengendalikan mesin untuk agen AI.
- Dua entri baru bernilai besar: [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) membawa organisasi raksasa GPU ke lapisan penalaran semantik untuk LLM, sementara [floci-io/floci](https://github.com/floci-io/floci) menantang emulator AWS berbayar dengan pendekatan gratis.
