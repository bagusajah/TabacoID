## 💡 Insight Minggu Ini

- **"Agentic infrastructure" mendominasi**: 7 dari Top 10 repo (ax, agent-native, superpowers, univer, substrate, harness-sdk, CLI-Anything) adalah tooling untuk membangun atau menjalankan AI agent — bukan aplikasi AI konsumen. Ekosistem sedang bergeser dari "chatbot" ke runtime/orkestrasi/harness.
- **Momentum rilis besar**: Dua dari tiga riser tercepat (google/ax v0.3.0 pada 20 Sep, dream-num/univer v1.0.0 pada 23 Sep) baru saja merilis versi penting — rilis versi mayor jelas terbukti menjadi pemicu lonjakan bintang.
- **Go dan TypeScript bersaing dengan Python di lapisan agent**: Meski Python masih umum (financial-services, claude-code-templates, harness-sdk, CLI-Anything), Go (ax, substrate) dan TypeScript (univer, agent-native, OpenStock) mengambil porsi besar di runtime agentic — sinyal bahwa tooling agent bergerak ke arah performa dan integrasi web.
