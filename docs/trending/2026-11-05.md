## Riset 3 Repo Teratas

### 1. vercel-labs/agent-desktop

[vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) kini memimpin trending dengan tambahan +2.470 bintang dalam sehari, hanya dua minggu setelah rilis perdana v1.0.0 pada 28 Oktober. Rilis stabil terbarunya adalah [v1.1.0](https://github.com/vercel-labs/agent-desktop/releases/tag/v1.1.0) yang dirilis 3 November 2026, sementara commit terakhir [d83bfaf](https://github.com/vercel-labs/agent-desktop/commit/d83bfafdc900be497450baf40098f8b6d843c5db) masih panas dari 5 November 2026. Proyek ini pernah mendapat sambutan besar di [Show HN-nya (99 poin, Mei 2026)](https://news.ycombinator.com/item?id=47982708) sebagai CLI otomasi desktop native untuk agen AI.

### 2. NVIDIA/auto-ontology

[NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) adalah framework Python untuk membangun lapisan penalaran berbasis graf semantik di atas data, memungkinkan generasi query deterministik dan konteks retrieval yang lebih explainable untuk LLM. Proyek ini masih [tanpa release](https://github.com/NVIDIA/auto-ontology/releases), menandakan code yang sangat baru, namun tetap mencuri +2.050 bintang dalam sehari. Pendorong utamanya jelas: [diskusi Hacker News "Nvidia – open-source auto-ontology" dengan 288 poin dan 142 komentar](https://news.ycombinator.com/item?id=50348962) pada 3 November 2026, plus commit terakhir [2a24f5d](https://github.com/NVIDIA/auto-ontology/commit/2a24f5d34ef6b6e168a7f22d308504d3ab36a198) pada 4 November 2026.

### 3. D4Vinci/Scrapling

[D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling) adalah framework web scraping "serba-nangkap" untuk Python yang mengklaim menangani semuanya dari satu request sampai crawl skala penuh. Momentum hari ini (+2.005 bintang, total kini ★ 96.623) dipicu oleh rilis [v0.5.1](https://github.com/D4Vinci/Scrapling/releases/tag/v0.5.1) yang baru keluar 4 November 2026, hanya berselang beberapa jam dari commit terakhir [3a4bb5b](https://github.com/D4Vinci/Scrapling/commit/3a4bb5b0a008233c85269a0a38a6d08edd4ce329) pada tanggal yang sama. Diskusi HN-nya sudah lama — [thread 2024](https://news.ycombinator.com/item?id=41832425) hanya 4 poin — jadi gelombang ini murni digerakkan komunitas scraping, bukan media.
