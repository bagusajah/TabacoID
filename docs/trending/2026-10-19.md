## Riset 3 Repo Teratas

Rilis stabil terbarunya adalah [v1.7.2](https://github.com/MadsLorentzen/ai-job-search/releases/tag/v1.7.2) (29 September 2026), bagian dari ritme rilis yang konsisten sejak [v1.0.0](https://github.com/MadsLorentzen/ai-job-search/releases/tag/v1.0.0) pada Juli 2026. Pengembangan tetap ramai: commit terbaru [0f6480d](https://github.com/MadsLorentzen/ai-job-search/commit/0f6480d32e59d7651d920a5ec6d78ede2f4113bf) (18 Oktober 2026) memperbaiki mode pencarian hemat pada `freehire-search` lewat PR #631. Tidak ada thread HN yang membahas repo ini secara spesifik, jadi lonjakan bintangnya tampak murni dari adopsi organik komunitas Claude Code.

### 2. anthropics/claude-plugins-official

Direktori resmi plugin Claude Code milik Anthropic naik ke posisi 4 dengan +1.175 bintang hari ini (total ★ 42.736) — tanda kuatnya ekonomi plugin di sekitar Claude Code. Repo ini bebas rilis bertag: tidak ada release yang diterbitkan, karena distribusinya berbasis direktori/manifest langsung di repo. Aktivitas tetap tinggi dengan commit terakhir [ea10b21](https://github.com/anthropics/claude-plugins-official/commit/ea10b213686c90bb1984b2016937310e05336cf3) (16 Oktober 2026) yang menaikkan versi bundel plugin `incident-io`. Belum ada diskusi HN khusus tentang repo ini; momentumnya justru tercermin dari munculnya ekosistem plugin sejenis di trending, seperti [cursor/plugins](https://github.com/cursor/plugins) dan [android/skills](https://github.com/android/skills).
